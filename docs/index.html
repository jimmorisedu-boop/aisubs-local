Проверьте слова. Запустите весь пакет.

AISubs распознаёт речь, даёт исправить текст и тайминги, а затем рендерит одобренные ролики одной очередью. Видео и черновики остаются на вашем компьютере.

Открыть на GitHubУстановка
  • 01Пачка роликов идёт одной очередью, а не по одному файлу.
  • 02Auto работает без остановок; Manual добавляет проверку перед рендером.
  • 03Whisper, кэш и рендер работают локально без подписки.

Два режима. Одна очередь.

Выберите контроль, который нужен именно этому пакету. Настройки стиля и пакетная обработка доступны в обоих режимах.

AUTO

От файлов сразу к результату

Добавьте пачку и запустите. AISubs последовательно распознаёт речь и рендерит каждый ролик без остановок на проверку.

  • минимум действий для чистых исходников;
  • прогресс и ошибка видны по каждому файлу;
  • остановка срабатывает после текущего файла.
MANUAL

Проверка до дорогого рендера

Редактируйте слова и тайминги по мере готовности, массово одобряйте чистые файлы и отправляйте подтверждённую часть в один рендер.

  • предупреждения о неуверенно распознанных словах;
  • автосохранение правок и восстановление пакета;
  • повтор ошибок без перезапуска всей очереди.

Рабочий процесс студии

Транскрипция и проверка не блокируют друг друга: можно разбирать готовые ролики, пока очередь продолжает работу.

  1. 01Добавьте пакетПеретащите все исходники в одну очередь.
  2. 02Проверяйте готовоеОткрывайте транскрипты сразу после распознавания.
  3. 03Одобрите чистоеПодтвердите один файл или всё без предупреждений.
  4. 04Рендерите вместеЗапустите одобренные ролики одной пакетной командой.

Предсказуемо для рабочего проекта

Локально
Видео, звук и транскрипты не отправляются в облачный сервис. Сеть нужна для установки и первой загрузки модели.
Правки без потери ритма
Замена текста сохраняет пословные тайминги; при необходимости начало и конец слова редактируются вручную.
Без перезаписи
Если имя результата уже занято, AISubs планирует безопасное новое имя вместо молчаливой замены файла.
После перезапуска
Черновики, одобренные версии и состояние последнего Manual-пакета восстанавливаются с диска.

Запуск без отдельной сборки

Windows-установщик разворачивает локальный Python, ffmpeg и зависимости. Модель можно выбрать при установке или скачать при первом запуске обработки.

Открыть инструкцию
setup.bat → run.bat
