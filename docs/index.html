AISubs

Локальное Windows-приложение для пакетного создания субтитров с режимами Auto и Manual.

  • Windows 10/11
  • локальная обработка
  • CPU / CUDA
  • faster-whisper + ffmpeg
GitHub ↗ Установка ↗ @daipotestit ↗

Режимы обработки

Auto выполняет весь пакет без промежуточной проверки. Manual добавляет проверку текста и таймингов перед рендером; этот этап не обязателен для Auto.

Режим Назначение Процесс
Auto Обработка пакета без промежуточной проверки. Добавить файлы → запустить → получить результаты.
Manual Проверка текста и таймингов до пакетного рендера. Распознать → проверить и одобрить → отрендерить одобренное.

Технические характеристики

ОС
Windows 10/11, 64-bit.
Распознавание
faster-whisper с пословными таймкодами.
Вычисления
NVIDIA CUDA при наличии; автоматический переход на CPU.
Видео
Локальная обработка и рендер через ffmpeg.
Данные
Исходники, транскрипты, кэш и результаты остаются на компьютере.
Manual
Черновики и ревизии сохраняются на диске и восстанавливаются после перезапуска.
Результаты
Если имя занято, создаётся новый файл без молчаливой перезаписи существующего.
